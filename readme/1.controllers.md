# 关于控制器、控制器方法`Controller`

## 命名与位置

控制器类名 = `ucfirst(控制器名) + 控制器后缀`，后缀由 `request.ini` 中 `suffix[controller]` 指定，默认 `Controller`；
命名空间为 `\application\{_VIRTUAL}[\{_MODULE}]\controllers\`，目录由 `request.ini` 中 `directory` 指定，默认
`/application`。

```
application/www/controllers/IndexController.php  →  \application\www\controllers\IndexController
application/www/jobs/controllers/ReportController.php → \application\www\jobs\controllers\ReportController
```

控制器必须继承自 `\esp\core\Controller`（通常先做一个 `_Base.php` 基类，再由各控制器继承它），否则报错：

```php
<?php
namespace application\www\controllers;

use esp\core\Controller;

class IndexController extends Controller
{
    public function indexAction()
    {
    }
}
```

控制器由 `Dispatcher` 以 `(new $class($dispatcher))` 方式创建，构造参数为 `Dispatcher` 本身，一般不要覆盖构造函数。

## 动作 Action 的命名

实际执行的方法名 = `strtolower(动作名) + 方法名后缀`，后缀由 `request.ini` 中 `suffix` 决定，默认：

| 请求方式                   | 后缀                | 示例方法          |
|------------------------|-------------------|---------------|
| 普通 GET                 | `Action`          | `indexAction` |
| POST（含 ajax 方式的 POST）  | `Post`            | `indexPost`   |
| GET 方式的 ajax           | `Ajax`            | `indexAjax`   |
| CLI                    | `Cli`             | `indexCli`    |
| 其它 method（PUT/DELETE…） | `ucfirst(method)` | `indexPut`    |

注意：`Ajax` 只匹配 **GET 方式** 的 ajax；POST 方式的 ajax 仍走 `Post`。

`suffix` 可在 `request.ini` 中修改，例如把 `get` 改为空则不追加后缀：

```ini
suffix[get] = Action
suffix[ajax] = Ajax
suffix[post] = Post
suffix[cli] = Cli
```

### 找不到时的降级顺序

若 `indexGet` 不存在，按以下顺序查找，仍找不到则该请求返回 `[...] nonexistent`：

1. `indexAction`（固定 `Action` 后缀，不受 `suffix` 影响）
2. `defaultGet`（即 `default` + 当前后缀）
3. `defaultAction`

## 生命周期

一次请求中，以下方法如果存在且可调用，会被自动执行：

| 方法                             | 时机                     | 说明                       |
|--------------------------------|------------------------|--------------------------|
| `_init{ActionExt}` / `_init`   | Action 之前              | 一般放在基类 `_Base` 中做登录、权限判断 |
| `_main{ActionExt}` / `_main`   | Action 之前，在 `_init` 之后 | 一般放在实际控制器中               |
| `_close{ActionExt}` / `_close` | Action 之后              | 收尾，参数为控制器的返回值            |

- 带后缀的优先于不带后缀的，例如 CLI 下先找 `_initCli`，没有再找 `_init`。
- `_init`、`_main` 若返回 **任何非 null 的值（包括 `false`）**，则中断后续流程，不再执行 Action，直接进入 `_close`；返回
  `false` 时传给 `_close` 的是 `null`。
- `_close` 的返回值若非 `null`，将替换掉控制器最终的返回值。

```php
class _Base extends Controller
{
    public function _init($controller, $action)
    {
        //返回 null 才会继续往下执行
        if (!$this->isLogin) return $this->redirect('/login');
        return null;
    }

    public function _close($value)
    {
        return $value;
    }
}
```

## 返回值与网页展示内容方式

`Action` 的返回值决定最终输出（见 [结果显示](./7.response.md)），概要：

| 返回                | 结果                                                |
|-------------------|---------------------------------------------------|
| `null`（或不 return） | 渲染视图，这是默认方式，此时视图文件必须存在                            |
| `array`           | 以 `application/json` 输出，`?callback=xxx` 时输出 jsonp |
| `string`          | 首字符为 `<` 按 `text/html`，否则 `text/plain`            |
| `int`             | 按状态码显示（如 404、500）                                 |
| `bool`            | 不输出任何内容                                           |
| 对象                | 有 `display()` 方法则调用它，否则转字符串                       |

在 Action 中也可以用以下方法指定输出内容，**调用后 Action 必须返回 `null`（或不 return）才会生效**：

```php
$this->html(string $value);          //text/html，显示 print_r($value) 的结果
$this->json(array $value);           //application/json，支持 ?callback= 的 jsonp
$this->xml($root, $value);           //text/xml，$root 为根节点名；也可只传数组，根节点默认为 xml
$this->php(array $value);            //serialize() 后的串，application/octet-stream
$this->text(string $value);          //text/plain，print_r() 输出
$this->image(string $value);         //base64 图片串（可带 data:image/...;base64, 前缀），输出 image/png
$this->md($mdFile);                  //以 Markdown 方式渲染
```

`$this->html()` **不带参数** 时清除之前设置的内容，回到默认的视图渲染方式，也就是以最后执行的为准。

上述 5 种（除默认外）方式都不会产生视图，若设置后仍需要视图，在最后执行 `$this->html();` 即可。

## 视图变量

在控制器中向视图传送变量的几种方式：

```php
$this->assign($name, $value);            //送至 Response，最终并入子视图，优先级最高
$this->getView()->assign($name, $value); //送至子视图(View)对象
$this->getLayout()->assign($name, $value); //送至框架视图(layout)
$this->getAdapter()->assign($name, $value); //送至标签解析器
```

- `$name` 可以是数组，一次送多个值。
- 最终送入子视图的数组为 `Response 的变量 + View 的变量`（前者键名覆盖后者），所以 `$this->assign()` 优先于
  `$this->getView()->assign()`，与先后顺序无关。
- 若启用了标签解析器，变量交给解析器处理；`$this->setAdapter(false)` 可以在当前请求中关闭解析器。

另有 7 个框架变量由系统统一生成并送入 `layout`：`_js_head`、`_js_body`、`_js_foot`、`_js_defer`、`_css`、`_meta`、`_title`；
若关闭了 layout（ `$this->setLayout(false)` ），这些变量会被释放到子视图中。详见 [视图](./2.views.md)。

## 视图、框架、资源相关方法

```php
$this->setView('index/list');            //指定视图文件，不含 .php 后缀时也自动补全
$this->setView(false);                   //关闭视图
$this->setLayout('layout');              //指定框架文件
$this->setLayout(false);                 //关闭框架
$this->setViewPath('/template/default'); //重新指定视图目录，@开头为绝对目录，/开头为相对 _ROOT
$this->getViewPath();
$this->ajax('index/list');               //ajax 请求时自动关闭 layout 并换视图
$this->title('文章标题');                 //三态，见 [结果显示](./7.response.md)
$this->keywords('关键字');
$this->description('描述');
$this->meta('name', 'value');
$this->css('/css/a.css');                //可传数组
$this->js('/js/a.js', 'foot');           //位置可选：head, body, foot(默认), defer
$this->concat(true);                     //合并 js/css
$this->render(false);                    //关闭自动渲染，=false 时什么都不输出
$this->cache(false);                     //本次请求不保存缓存
$this->markdown('# 标题');                //返回 markdown 转 html 后的串；传文件路径时读文件
$this->md('/md/readme.md');              //以 markdown 方式输出
```

## 读取配置与枚举

```php
$this->config('database.redis.host');    //读 config，支持 a.b.c 多级；第 2 个参数传 int/float/bool 可转换类型
$this->enum('state', 1);                 //读 enum.state 中键为 1 的值
$this->setEnum('enum');                  //向视图送入一个名为 enum 的闭包，视图中可直接调用
```

`enum` 的第三个参数 `$hide`：整型且 >0 表示只显示这些键，<0 表示剔除这些键；数组同理，元素为负表示剔除。

## 请求与跳转

```php
$this->getRequest();                     //Request 对象
$this->redirect('/login', 302);          //跳转，之后 exit
$this->exit('文本');                      //输出并结束客户端，之后 exit
$this->finish('说明');                    //只结束客户端，后面代码继续执行
$this->reload('other', 'list', 1, 2);    //重新分发到 模块/控制器/动作/参数
$this->jump('list');                     //reload 的别名
$this->check_host('a.com', 'b.com');     //检查 referer 是否本站或指定域名，否则 exit('禁止接入')
$this->header('X-Name', 'value');        //自定义响应头
```

`reload()` 会重新走一次分发（Response 重新初始化、控制器重新加载）；若路径、模块、控制器、动作四项都没变，返回 `false`，不真跳。

## 异步、锁、调试

```php
$this->task('className.method', $args, $after); //发布后台任务，见 [异步任务](./22.task.md)
$this->publish('action', $message);      //发送到 redis 管道
$this->queue('action', $data);           //发送到 redis 队列
$this->async('taskKey', $args, $runTime);//保存到 {_RUNTIME}/async，见 [异步](./23.async.md)
$this->locked('lockName', function () { }); //带锁执行，见下文
$this->shutdown(function () { });        //注册 shutdown 回调，先注册先执行
$this->debug($data);                     //写入 debug 日志，见 [调试器](./20.debug.md)
$this->error($data);
$this->debug_mysql($data);
$this->ignoreError(__FILE__, __LINE__ + 1); //屏蔽指定行的错误
$this->onError(function ($err) { });
```

### 带锁执行 locked

```php
$val = $this->locked('orderPay', function ($orderID) {
    //锁内的业务
    return $result;
}, $orderID);

if (is_string($val)) {
    //字符串表示出错或被占用：'locked'、'locked: Running'、'locked error'、'锁名不可含特殊字符…'
}
```

- 锁名限 1-50 字符，只能含 `[\w\-\.]`。
- 锁名以 `redis` 结尾 → redis 锁；以 `go` 结尾 → 交给 `/tmp/locked_pipe` 上的 go 常驻服务；否则文件锁（
  `/tmp/flock_{key}.flock`）。
- 锁名的**首字符若是数字，会被当作 option 位**：`1`=非阻塞（拿不到立即返回），`2`/`4`=延长等待（文件锁时 `2` 表示结束后不删除锁文件），
  `8`=redis 释放时用 lua 校验。
- 因为出错信息用字符串表示，所以**锁内业务不要返回字符串**。

## 其它可用成员

| 成员                                                                                          | 说明                                  |
|---------------------------------------------------------------------------------------------|-------------------------------------|
| `$this->_config`                                                                            | `Configure` 对象                      |
| `$this->_request` / `$this->_response` / `$this->_dispatcher`                               | 请求、响应、调度器                           |
| `$this->_redis`                                                                             | config 中创建的 redis 实例                |
| `$this->_cookies` / `$this->_cache` / `$this->_debug` / `$this->_error` / `$this->_counter` | 各组件对象，未启用时为 null                    |
| `$this->_plugs`                                                                             | 已注册插件数组                             |
| `$this->tempData`                                                                           | 空数组，供程序运行中保存全局唯一变量，建议在 `_close` 中处理 |
| `$this->cid('_SSI')`                                                                        | 客户端唯一标识，需启用 Cookies                 |
| `$this->uniqid('md5')`                                                                      | 生成唯一键                               |
| `$this->getPlugin('name')`                                                                  | 取已注册插件对象                            |
| `$this->getPool()`                                                                          | 取数据库连接池 `esp\dbs\Pool`              |
| `$this->getResource()`                                                                      | 取 `Resources` 对象                    |
| `$this->run_user('www')`                                                                    | 仅 CLI，强制以某账号运行                      |
| `$this->subscribe(callable)`                                                                | 仅 CLI，侦听 redis 管道                   |
| `$this->frameVersion()`                                                                     | php/redis/swoole/esp 版本号            |
| `$this->rpc($uri, $data)` / `$this->newRpc($conf)`                                          | RPC 调用                              |
