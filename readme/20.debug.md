# 关于`Debug`

## 开启

- 在 `{_RUNTIME}` 下创建 `debug.lock` 文件即进入 debug 环境，常量 `_DEBUG` 取其文件内容（空文件时为 `true`）；
- 同时还需要 `debug.ini` 中 `run = true`，否则不创建 Debug 对象。

## 配置文件 debug.ini

```ini
[default]
;调试 Debug 开启，若不定义，则不启用
run = true

;是否自动启动记录，若 = false，则需要在控制器中手动 start() 打开
auto = true

;耗时过长报警，ms
limit = 10000

;单一线程中执行 sql 次数超过此值报警
mysql_limit = 10

;所有本系统可能的 host，不在此范围内的，均列到【hackers】目录
host[] = blog.com

;正常日志文件保存目录
path = {_RUNTIME}/debug/{DATE}/

;错误日志
error = {_RUNTIME}/error

;警报日志
warn = {_RUNTIME}/warn

;正常日志文件保存目录名的规则，用于 date() 函数
rules[folder] = ''

;正常日志文件名规则，用于 date() 函数
rules[filename] = H_i_s

;记录错误的文件命名规则，这里指 date() 函数的参数
rules[error] = E_ymdHis_

;是否记录 mysql 所有语句
print[mysql] = true

;是否记录接收到的 POST 内容
print[post] = true

;是否记录最后打印 html 结果
print[html] = true

;是否记录 _SERVER 内容
print[server] = true
```

## 控制器中记录

```php
$this->debug($data);              //记录任意内容，数组、对象均可
$this->debug();                   //返回 Debug 对象本身，可继续调用其方法
$this->error($data);              //记录一条错误
$this->debug_mysql($data);        //记录 mysql 语句
$this->debug()->folder('pay');    //指定日志子目录
```

Debug 对象常用方法（`esp\debug\Debug`）：

```php
$this->debug()->relay($data);     //同 $this->debug($data)
$this->debug()->error($data);
$this->debug()->save_logs('标签'); //立即保存
$this->debug()->filename();       //当前日志文件名
```

## 保存时机

- `$this->_debug->mode === 'none'`：不保存；
- `mode === 'cgi'`，或 URL 中带 `?_debug=1`：立即保存（`_debug=1` 时还会 `var_dump` 保存结果）；
- 其它：用 `register_shutdown_function()` 在脚本结束时保存，因此不影响客户端响应。

也就是说，**生产环境只要不建 `debug.lock`、或 `debug.ini` 中 `run = false`，就不会产生日志**。

## 屏蔽已知错误

对于明确知道会出错、又不希望写日志的行，可以提前登记：

```php
$this->ignoreError(__FILE__, __LINE__ + 1);   //屏蔽下一行的错误
$this->ignoreError(__FILE__, __LINE__);       //屏蔽当前行
```

也可以注册统一的错误回调：

```php
$this->onError(function ($err) {
    //$err: file, line, message
});
```

## 全局错误处理

`esp\core\Handler` 在启动时注册了 `set_error_handler` 与 `set_exception_handler`，
未捕获的错误与异常统一输出 `500` 状态码 + `[code]message`，并交给 Debug 记录（若已启用）。

## 性能计时

`$option` 中只要存在 `timer` 键（任意值），就会创建 `esp\debug\Timer`，在路由、分发、渲染等各阶段打点，用于排查耗时。

## 与 _CONFIG_LOAD

`option.php` 中的典型写法：

```php
$option['before'] = function (&$option) {
    define('_CONFIG_LOAD', _DEBUG);
};
```

`_CONFIG_LOAD` 为真时，config 与路由**每次都从文件重新加载**，不读缓存，
这样开发时改配置、改路由表立即生效；生产环境下 `_DEBUG` 为假，走缓存。
