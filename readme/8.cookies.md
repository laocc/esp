# 关于`Cookies`和`Session`

## Cookies 配置 cookies.ini

```ini
[default]
run = false

;是否将 domain 转换保存到 host 下
;若不转换，则 aaa.abc.com 中的 cookies 在 bbb.abc.com 下无效
;转换后，则 aaa.abc.com 和 bbb.abc.com 下的 cookies 是相同的
domain = host    ;可选 host 或 domain

[www]
run = true
```

- `domain = host`：Cookie 写在根域（`_HOST`）下，各子域共享；
- `domain = domain`（或任何非 `host` 值）：Cookie 写在当前完整域名（`_DOMAIN`）下。

Cookie 统一按小写键名存取，且固定 `path=/`、`httponly=true`、`samesite=Lax`、`secure` 随 `_HTTPS`。

## 使用方法

`$this->_cookies` 即为 `esp\core\Cookies` 对象（未启用时为 `null`）：

```php
$this->_cookies->get('key');              //读取，不存在返回 null
$this->_cookies->get('key', '默认值');     //带默认值
$this->_cookies->get();                   //返回整个 $_COOKIE
$this->_cookies->set('key', 'value', '30d');
$this->_cookies->del('key');
$this->_cookies->disable();               //删除当前所有 cookie
```

`set()` 的第 3 个参数：

- 不传时按源码取值 `time() - 1`（即立即过期），**因此建议总是显式指定有效期**；
- 传字符串，支持 `1y`(年)、`1m`(月)、`1w`(周)、`30d`(天)、`12h`(小时)，大小写均可；
- 也可以直接传 unix 时间戳；
- 传数组时值会被 `json_encode`。

客户端唯一标识：

```php
$this->cid();              //默认键名 _SSI，100 年有效
$this->cid('_SSI', true);  //返回纯数字
```

`cid()` 需要站点启用 Cookies，否则报错。

在 header 已发送之后再写 Cookie 会报错：`Cookies: Header be Send:...`，所以 Cookie 操作要放在输出之前（控制器中是安全的）。

## Session 配置 session.ini

```ini
[default]
;注意：session 启用的前提：
;1,当前站点的 cookies 必须也得是开启状态
;2,php.ini 中 session.auto_start = 0
run = false

key = SESS          ;COOKIES 的键名
prefix = S          ;COOKIES 键值的前缀

;存储介质：files=PHP 原生文件方式，redis=保存到 database.ini 中指定的 redis
;若用其他 redis 服务器，则需要在当前页定义 [redis] 节点，子项与 database.redis 相同
driver = redis

expire = 86401      ;在存储介质中保存多久，0=与浏览器同生命期
cookie = 864000     ;session 键在 cookie 中保存多久，不能小于 expire
limiter = nocache   ;nocache, public, private_no_expire
delay = 1           ;有更新时是否自动延期
domain = domain     ;指定为 host 时，www.abc.com 生效于 .abc.com
```

要点：

- **只有 `cookies.run = true` 时 session 才会被创建**，两者是父子关系；
- `driver` 不指定时跟随 config 的驱动；
- 用 redis 时，若 `db` 与 config 所在库相同，则复用 `Configure::_Redis`，否则新建连接；
- 框架在渲染输出前会调用 `session_write_close()`。

Session 由 `laocc/esp` 依赖的 `esp\session\Session` 实现，读写方式与原生一致：`$_SESSION['key']`。

## 检查

项目根目录下有 `check.php`，可直接执行检查 redis 扩展与 `session.auto_start`：

```
php vendor/laocc/esp/check.php
```
