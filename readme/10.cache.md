# 关于缓存及生成静态文件`Cache`

页面级 HTML 缓存，配置文件：`cache.ini`。
配置支持 `[default]` + 虚拟机/域名节点，合并顺序为 `default` > `_VIRTUAL` > `_HOST` > `_DOMAIN`。

## 完整示例

```ini
[default]
;是否启用 cache
run = false

;压缩方式，以下几种值相加
;1 = 删除空行
;2 = 合并 2 个以上空格
;4 = 删除 HTML 注释
;8 = 删除 HTML 之间的空格
;16 = 全部 HTML 归为一行
;   若启用"全部归为一行"，注意 js 也会被归为一行，js 行尾若没加 ; 号可能出问题
compress = 1

;存储方式，可选：redis、file(默认)
;用 redis 时，过有效期自动清除；用 file 时过期文件不会自动删除，需要手动或用其他规则清理
medium = file

;域名隔离模式，相同控制器可能被绑多个域名，生成 key 时是否不同域名用不同 key
;0 = 不隔离，1 = 隔离根域名(host)，2 = 隔离子域名(domain)
isolation = 0

;缓存保存目录，分别是：动态缓存模式、静态模式
;medium = file 时，缓存文件目录
;静态文件目录，若不设置，保存在 web 入口处
;单独指定时，一般保存在 .gitignore 中屏蔽的目录
;需在 nginx 中重定向文件目录： location ^~ /KEY/ {root PATH;}
path[cache] = {_RUNTIME}/html_cache
path[static] = {_RUNTIME}/html_static


[www]
run = true

;缓存保存时间（秒），仅对动态缓存方式有效
;静态文件若要更新，只能手工删除静态文件或用程序重新生成
ttl = 0

;按"控制器[动作]"单独设置：
;   false 或 0：关闭该项的缓存
;   1~4：仅开启静态缓存，动态缓存不开启
;   >=5：作为该项的动态缓存有效期（5 秒以下没有意义），同时替换 ttl 值
;不设 ttl（或 =0）的控制器/动作不产生缓存
index[index] = 5

;URI 符合下面规则的，额外生成静态 HTML
;注意：生成的文件名按 URI 保存，也就是 url 中 ? 号、# 号后的信息不会被记录，
;      所以这两者之后的值不要与内容相关联
static[html] = '/^\/index\/index\/\d+\.html([\?\#].*)?$/i'
static[arts] = '/^\/article\/\w+\/.+\.html([\?\#].*)?$/i'

;$_GET 中以下参数若存在，参与缓存键的命名，未指定的 get 参数忽略
params[] = name
params[] = age
```

## 工作过程

1. **读取**：`Dispatcher` 在分发到控制器之前调用 `Cache::Display()`。命中则直接输出并调用 `fastcgi_finish_request()` 结束客户端，控制器不会被执行。
2. **保存**：客户端断开之后调用 `Cache::Save()`，把本次输出的结果保存起来。

命中与保存的前提条件：

- `run = true` 且 `ttl >= 0`（`ttl` 默认为 `-1`，即完全不启用，必须显式设置才有效）；
- 未定义常量 `_CACHE_DISABLE`，且 URL 中没有 `?_CACHE_DISABLE=1` / `?_cache_disable=1`；
- 输出内容必须包含完整的 `<html>...</html>`；
- 控制器中没有调用 `$this->cache(false)`。

动态缓存文件只在 `ttl >= 5` 时落盘；`ttl` 在 1~4 之间时只生成静态文件，`ttl = 0` 时不写任何缓存（但仍会读取已存在的缓存文件）。

## 缓存键与文件

缓存键由以下各项 json 后 base64 得到：

```
virtual, module, controller, action, params, 指定的 $_GET 参数, 隔离域名
```

- `medium = file`：文件名为 `md5(缓存键).php`，保存在 `path[cache]` 下；文件内容是一个 base64 后的 PHP 返回数组，不会因正文中含 `<?php` 或引号而损坏；
- `medium = redis`：键为 `md5(缓存键)`，写入时带 `ttl`，过期自动清除。

页面中的 `{CACHE_KEY}`、`{CACHE_TIME}` 会在保存时被替换成实际的缓存键与保存时间。

## 控制器中的控制

```php
$this->cache(false);   //本次请求不保存缓存（读取不受影响）
$this->cache(true);    //恢复
```

按控制器/动作设置（`index[index] = 5` 这种写法）在 `Cache::Display()` 中生效，
可以针对某几个页面单独开关或单独设有效期。

## 静态 HTML

配置了 `static[...]` 且 URI 匹配时，会把结果写到 `path[static] + URI`；
键名为 `index` 的规则比较特殊：URI 为 `/` 时，用配置的值直接作为文件名。

因为文件名就是 URI，所以 nginx 要按目录做重定向：

```
location ^~ /index/ {
    root /ROOT/runtime/html_static;
}
```

静态文件不会自动更新，只能删除后重新生成，或用 js 请求判断是否强制刷新。

## 多域名混用时的配置

如果一个站同时用多个域名，但无论用哪个域名访问结果都相同，则不需要隔离域名，`isolation = 0` 即可。
而如果不同域名显示的内容并不一定相同，就需要隔离域名。
隔离域名分两种情况：根据根域名，或根据子域名。
在缓存模式下直接定义 `isolation = 1` 或 `2` 即可，但生成静态模式下还需要把不同域名的文件保存到不同目录中。

`cache.ini` 中指定不同目录：

```ini
path[cache] = {_RUNTIME}/html_cache/{_HOST}
path[static] = {_RUNTIME}/html_static/{_HOST}
```

`nginx.conf` 中要根据不同域名指向不同目录：

```
server    {
    listen 80;
    server_name www.art.com blog.art.com www.blog.com art.blog.com;
    index index.php;
    root /HOST_ROOT/public/www;
    include resource.conf;
    include php.conf;

    #隔离子域名时：
    location ^~ /index/ {
        root /HOST_ROOT/runtime/html_static/$host;
    }

    #隔离根域名时，因为 nginx 中没有根域名变量，这里需要分别重定义根域名：
    location ^~ /index/ {
        set $key $host;

        if ($host ~ "blog.com"){set $key "www.blog.com";}
        if ($host ~ art.com){set $key "www.art.com";}

        root /HOST_ROOT/runtime/html_static/$key;
    }

    access_log off;
}
```

`path[cache]`、`path[static]` 中可以使用 `{_HOST}`、`{_DOMAIN}`、`{_VIRTUAL}` 三个占位符。

## 清理

- `medium = file`：直接删除 `path[cache]` 下的文件即可（过期文件不会自动删除）；
- `medium = redis`：`esp -s flush 256` 清空当前库（会保留 `_RESOURCE_RAND_`），注意这也会清掉 config 缓存，之后会自动重建。
