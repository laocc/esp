# 关于结果显示`Response`

`$this->_response` 或 `$this->getResponse()` 即为 `esp\core\Response` 对象。

## 网页展示内容方式

1. **默认（HTML 视图）**：控制器没有 `return` 或 `return null`，按正常方式渲染视图，此时视图文件必须存在；
2. `html`：显示 `$this->html(...)` 中的内容，`text/html`；
3. `json`：显示 `$this->json(Array)` 的内容，`application/json`，支持 `?callback=xxx` 输出 jsonp；
4. `xml`：显示 `$this->xml('root', Array)` 的内容，注意参数是数组而不是已转换的 xml 串，`root` 为根节点名，`text/xml`；
5. `text`：显示 `$this->text(String)` 的内容，用 `print_r()` 输出，也就是说传入数组时显示为数组形式（不是 json），`text/plain`；
6. `php`：`$this->php(Array)`，输出 `serialize()` 结果，`application/octet-stream`；
7. `image`：`$this->image(String)`，base64 图片串（可带 `data:image/...;base64,` 前缀），输出 `image/png`；
8. `md`：以 Markdown 方式渲染，见 [视图](./2.views.md)。

上述方式中，只有 `默认` 方式会产生 `view` 对象；但在控制器中调用 `getView()` 时会提前自动创建，`getLayout()` 同理。

调用 `html()`/`json()`/… 之后，**Action 必须返回 `null`（或不 return）**，这些方法设置的才是最终输出；因为 `Response::display()` 优先按 Action 的返回值输出。

## 控制器返回值的处理

| 返回 | 结果 |
|---|---|
| `null` | 渲染视图 |
| `array` | `application/json`，`?callback=xxx` 时输出 jsonp；无法 json 序列化时返回带 `result`(serialize) 的错误结构 |
| `string` | 首字符为 `<` 时 `text/html`，否则 `text/plain` |
| `int` | 按状态码显示（404、500 等） |
| `bool` | 不输出任何内容 |
| 对象 | 有 `display()` 方法则调用它，否则转字符串 |

另外：

- 返回 `null` 且当前是 **ajax 请求** 时，直接结束，不渲染任何视图。所以纯 ajax 接口应当返回数组；
- `$this->render(false)` 可以关闭自动渲染，此时什么都不输出（与插件配合时用）。

## 自定义响应头、跳转、结束

```php
$this->header('X-Name', 'value');      //也可 $this->header(['X-Name', 'value'])
$this->redirect('/login', 302);        //跳转并结束客户端，之后 exit
$this->exit('文本');                    //输出文本并结束，之后 exit
$this->finish('说明');                  //只结束客户端，后面的代码继续执行
```

`redirect()` 若发现 header 已经发送过，会记一条 debug 错误并返回 `false`。

## 页面元素

```php
$this->title('文章标题');               //默认：拼成 "文章标题 - {response.ini 中的 title}"
$this->title('新站名', true);           //覆盖 response.ini 中的默认标题
$this->title('文章标题', false);        //只显示 "文章标题"，不带默认标题
$this->keywords('关键字');
$this->description('描述');
$this->meta('author', 'esp');
$this->css('/css/a.css');              //可传数组
$this->js('/js/a.js');                 //第 2 参数为位置：head、body、foot(默认)、defer
$this->concat(true);                   //合并页面中的 js/css
```

`concat(true)` 会把页面里所有本地的 `<link>` 与 `<script src>` 合并成
`{资源域名}/??a.css,b.css?{版本号}` 与 `{资源域名}/??a.js,b.js?{版本号}` 各一条，插到 `</head>` 之前。
外链（`http`、`//` 开头）不参与合并。

## 资源 Resources

`response.ini` 中可配置：

```ini
title = Esp
keywords = Esp
description = Esp

;资源域名，不以 / 或 http 开头时会自动补上协议
host = res.domain.com
;资源文件路径，输出时会把 path 替换成 host
path = /public/res

;是否合并 js/css
concat = false

;目标替换，输出 html 前做字符串替换
;interchange[/public/www/res] = /res
;interchange[/public/vui] = http://www.vui.com
```

页面中的 `__RAND__` 会被替换成资源版本号（存在 redis 的 `{_UNIQUE_KEY}_RESOURCE_RAND_` 中），
可用 `esp -s resource` 重置。

控制器中 `$this->getResource()` 可取到 `Resources` 对象，读写 `title`、`keywords`、`description` 等。

## 缓存标记

```php
$this->cache(false);   //本次请求不保存缓存，见 [缓存](./10.cache.md)
```

`Response::$cache` 由 `cache.ini` 中 `run = true` 时自动置为 `true`，控制器中可以临时关掉。
