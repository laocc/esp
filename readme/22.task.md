# 异步任务

控制器与 `Library`（Model）中都可调用以下方法。除 `shutdown` 外，都依赖 redis。

| 方法 | 类型 | 说明 |
|---|---|---|
| `publish` | 管道 | 发送消息到 redis 管道，一般由 swoole 的订阅端接收 |
| `queue` | 队列 | 发送到 redis 队列，另一端用 `lPop` 取出 |
| `task` | 后台任务 | 本质还是 publish，需要另外实现下面的 swoole `on('task')` 部分 |
| `async` | 文件 | 以文本方式保存到 `{_RUNTIME}/async` 目录，见 [异步](./23.async.md) |
| `shutdown` | 同步 | 不是异步任务，只是在客户端结束后执行 |

## publish 发布订阅

```php
$this->publish('actionName', $message);
```

- 管道名取常量 `_PUBLISH_KEY`，未定义时为 `REDIS_ORDER`；**建议不同项目定义不同的 `_PUBLISH_KEY`**；
- `$action` 中若含 `.`，则点号前作为管道名，点号后作为 action；
- 实际发送的是 `serialize(['action' => ..., 'message' => ...])`；
- CLI 环境下不可用（会报错），请直接用 redis 管道发送。

接收（一般在 swoole 中）：

```php
$this->subscribe(function ($redis, $channel, $msg) {
    //$msg 为 publish 的第二个参数
});
```

`subscribe()` 一般只用在 CLI 环境下。

## queue 队列

```php
$this->queue('actionName', $data);
```

- 队列键取常量 `_QUEUE_TABLE`，未定义时为 `REDIS_QUEUE`；
- 写入的是 `rPush`，读取：

```php
while ($data = $this->_redis->lPop($queKey)) {
    //...
}
```

> 不建议在 web 环境中使用队列，生产环境实测经常发生堵塞。

## task 发布后台任务

```php
$this->task('TaskClassName.methodName', ['id' => 1], 0);   //第 3 个参数为延迟秒数
$this->task('methodName', ['id' => 1]);                    //也可以只给方法名
```

- 任务键中的 `->`、`::` 会被换成 `.`，若含 `.` 则拆成 `class` 与 `action` 两项；
- 管道名取常量 `_TASK_KEY`；
- `_taskPlan_` 是专用词，自己 publish 时不要用这个关键词。

### 创建后台执行任务

需自行在 swoole 中实现 `on('task')`，并创建对应的 `Task` 类：

```php
$Server->on('task', function (Server $server, $task_id, $worker_id, $data) {
    $val = null;
    $action = strval($data['_action'] ?? ($data['action'] ?? ''));

    switch ($action) {
        case '_taskPlan_':
            $action = strval($data['message']['action'] ?? 'null');
            $modTask = new Task();
            if (method_exists($modTask, $action) and is_callable([$modTask, $action])) {
                $val = $modTask->{$action}(...($data['message']['params'] ?? []));
            } else {
                $val = "library\\Task::{$action}()方法不存在";
            }
            break;

        default:
            $val = [
                'error' => '未知任务',
                'taskID' => $task_id,
                'workID' => $worker_id,
                'time' => date('Y-m-d H:i:s'),
                'data' => $data
            ];
            break;
    }

    if (is_string($val)) _echo($val, 'red');
    return $val;
});
```

## shutdown 客户端结束后执行

```php
$this->shutdown(function ($a, $b) {
    //...
}, $a, $b);
```

先注册的先执行，最后框架还要保存 debug 日志。
CLI 环境下会**立即同步执行**（不注册 shutdown 函数）。

## 相关常量

| 常量 | 默认值 | 用途 |
|---|---|---|
| `_PUBLISH_KEY` | `REDIS_ORDER` | publish / subscribe 的管道名 |
| `_TASK_KEY` | `_TASK_KEY` | task 的管道名 |
| `_QUEUE_TABLE` | `REDIS_QUEUE` | queue 的队列键 |

建议在 `option.php` 或 bootstrap 中统一定义。
