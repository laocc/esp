# 关于数据模型`Model`

## 类关系

```
esp\core\Controller          控制器
    ↑ 持有
esp\core\Library             业务工作类基类（Model/Library/Service 都可直接继承它）
    ↑
esp\dbs\DbModel              laocc/dbs 提供的数据模型基类
    ↑
esp\help\EspModel            本框架对 DbModel 的空实现，供 CLI 工具使用
```

- 实际项目中的 Model 一般继承 `esp\dbs\DbModel`（或项目自己的 `_BaseModel`）；
- 不做数据库操作的工作类（如封装第三方接口、业务逻辑）可以直接继承 `esp\core\Library`；
- 二者都不需要手工传入控制器：构造函数会用 `debug_backtrace()` 向上查找创建它的 `Controller`/`DbModel`/`Library`，从而拿到 `$this->_controller`。

## 创建与使用

Model 文件一般放在 `/models` 目录（默认值，可用 CLI 参数修改），基类默认 `_BaseModel`：

```php
<?php
namespace application\www\models;

class UserModel extends _BaseModel
{
    public function getUser(int $userID)
    {
        return $this->table('user')->where(['userID' => $userID])->get();
    }
}
```

在控制器中直接 `new` 即可：

```php
$modUser = new UserModel();
$user = $modUser->getUser($userID);
```

在 CLI、或在 swoole 的 tick/task 这类回调中创建时，调用栈里没有控制器，必须把控制器（或任意一个 Model、Library 实例）作为**第一个参数**传入：

```php
$modUser = new UserModel($this, ...$args);   //$this 为控制器或另一个 Library 实例
```

否则报：`Library中无法获取Controller`。

## 自动创建 Model 文件

框架自带 CLI 工具，可根据数据库表结构生成 Model 文件：

```
esp -s model            ;在 /models 下按表生成，基类 _BaseModel
esp -s model /app/models _BaseModel
```

相关命令：

```
esp -s tables                   ;显示所有表
esp -s table user               ;打印 user 表的字段结构，第 2 参数为生成数组时的键名，默认 data
```

`esp` 即项目中的 `public/cli/index.php`，框架自带的 `esp.sh` 可在项目任意子目录下直接调用它。

## 数据库配置

配置文件 `common/config/database.ini`：

```ini
[mysql]
master = /tmp/mysql.sock
db = dbName
username = userName
password = userPwd
charset = utf8mb4
collation = utf8mb4_general_ci
persistent = false
timeout = 1
prefix = ''

;Model 的数据缓存方式：
;int      = redis 表 ID，数据以主键方式保存，可设过期时间
;string   = 采用 hash 方式，无有效期
;true     = 用 dbName 作 hash 键保存
;false    = 不启用缓存（默认）
cache = 4

[redis]
host = /tmp/redis.sock
port = 0
maxDb = 16
timeout = -1
prefix = ""
pconnect = 0

;不同用途可以分不同的库
;db[config] = 5    ;配置数据，包括计数器等
;db[model] = 5     ;Model 中产生的数据
;db[session] = 5   ;仅指 session
```

控制器中取连接：

```php
$this->_redis;        //config 中创建的 redis 实例，可直接用
$this->getPool();     //esp\dbs\Pool 连接池，按 $this->_config->get('database') 创建
```

## Library 通用能力

继承 `esp\core\Library` 后可直接调用：

```php
$this->Controller();                 //取控制器对象
$this->config('database.redis.host');//读配置
$this->enum('state', 1);             //读枚举
$this->debug($data);                 //写 debug 日志
$this->locked('key', function () {});//带锁执行
$this->publish / task / queue / async; //同控制器，见 [异步任务](./22.task.md)
$this->rpc($uri, $data);
$this->redirect($url);
$this->shutdown(function () {});
$this->ignoreError(__FILE__, __LINE__ + 1);
```

`Library` 中若定义了 `_init`、`_main`，构造时会被自动调用（参数即构造参数，若第 1 个参数是控制器则自动剔除）；
若定义了 `_close`，析构时自动调用。
