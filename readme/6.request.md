# 关于请求方法控制`Request`

`$this->_request` 或 `$this->getRequest()` 即为 `esp\core\Request` 对象。

## 配置文件 request.ini

```ini
[default]
;程序主目录
directory = '/application'

;路由设置目录
router = '/common/routes'

;控制器、Model 的类名后缀
suffix[controller] = Controller
suffix[model] = Model

;不同请求方式对应的控制方法名后缀，见 [控制器](./1.controllers.md)
suffix[get] = Action
suffix[ajax] = Ajax
suffix[post] = Post
suffix[cli] = Cli

;允许或禁止的控制器名，可以直接是控制器名，也可以是正则表达式
;allow[] = index
;disallow[] = index

;控制器不存时的返回内容
;empty[default] = 页面不存在

[www]
;控制器映射别名
alias[aaa] = bbb

;虚拟机映射，将本入口的请求交由另一个虚拟机实现
;此时 $request->virtual = app，但 _VIRTUAL 仍为 www
;virtual = app
```

说明：

- `directory`、`router` 中 `/` 开头表示相对 `_ROOT`，也可以用绝对路径；
- `suffix[controller]`、`suffix[model]` 只作为类名后缀，会被从方法名后缀列表中剔除；
- `[default]` 为所有虚拟机公用，虚拟机节点（如 `[www]`）中的同名项覆盖它。合并顺序为 `default` > `_VIRTUAL` > `_HOST` > `_DOMAIN`，也就是说可以用虚拟机名、根域名、完整域名做更精细的区分；
- 早期版本中的 `action[]`、`concurrent`、`counter` 三项目前已不被读取，`counter` 相关配置请见 `counter.ini`。

## 常用属性

| 属性 | 说明 |
|---|---|
| `virtual` | 实际生效的虚拟机，可被 `virtual` 配置或路由改变 |
| `module` | 模块 |
| `controller` / `action` | 控制器名、动作名，均为小写，不含后缀 |
| `params` | 参数数组 |
| `method` | `GET`/`POST`/`AJAX`/`CLI` 之一；GET 方式的 ajax 为 `AJAX` |
| `directory` / `router_path` | 程序主目录、路由表目录 |
| `referer` | 来路 |
| `contFix` / `suffix` | 控制器后缀、方法名后缀表 |
| `exists` | 是否命中了正常的控制器 |
| `namespace` | 命名空间前缀，一般由路由指定 |
| `router` | 命中的路由规则名 |

`Request` 也实现了 `__get()`/`__set()`，可以当作中转变量用：

```php
$this->_request->set('userID', 123);
$this->_request->get('userID');
$this->_request->userID;              //同上
```

## 常用方法

```php
$this->_request->getMethod();         //GET / POST / AJAX / CLI
$this->_request->isGet();             //普通 GET；isGet(true) 时把 ajax 的 GET 也算在内
$this->_request->isPost();            //POST，默认含 ajax 的 POST；isPost(false) 则排除
$this->_request->isAjax();
$this->_request->isCli();
$this->_request->ip();                //客户端 IP，同 _CIP
$this->_request->ua();                //User-Agent
$this->_request->id();                //本次请求唯一 ID，同 $_SERVER['REQUEST_ID']
$this->_request->key();               //md5(IP + UA + _DOMAIN)
$this->_request->getControllerKey();  //供缓存分组用的键
$this->_request->RouterValue();       //路由结果数组
$this->_request->getParams();
$this->_request->getParam('name');
$this->_request->setParam('name', $value);
```

客户端判断：

```php
$this->_request->agent();             //['agent','browser','version','os']
$this->_request->is_wap();            //是否手机端
$this->_request->is_ios();
$this->_request->is_android();
$this->_request->is_ie();
$this->_request->is_wechat();         //微信
$this->_request->is_weChatTools();    //微信开发者工具
$this->_request->is_alipay();         //支付宝
$this->_request->is_robot();          //是否真实浏览器（返回 true 表示不是真实浏览器）
$this->_request->is_spider();         //是否爬虫
```

> 以上判断基于 UA 关键字，不保证百分百准确，`is_robot()` 为 `true` 表示判定为爬虫/非真实浏览器。

控制器中还封装了来路检查：

```php
$this->check_host();                  //只放行本站 _HOST 或空来路：用 $this->check_host('')
$this->check_host('a.com', 'b.com');  //额外放行这两个域名
```

## 运行环境

`_URI` 即路由依据，等于 `REQUEST_URI` 中的 path 部分；CLI 环境下由命令行参数拼成 `/a/b/c`。
`Dispatcher` 对 `HEAD` 请求直接 `exit('OK')`，对 `/favicon.ico` 直接返回一张空图，建议在 nginx 层直接拦截这两者。
