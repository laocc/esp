# 文件方式异步任务`async`

以文件方式保存任务到 `{_RUNTIME}/async` 目录，由另一个进程读取并执行。
与 redis 的 `publish`/`queue`/`task` 相比：

- 优点：可以指定执行时间，基于文件稳定性较高；
- 缺点：**只限于前后端在同一服务器**，多服务器环境请用 redis 管道；
- 框架源码中的注释也建议优先使用 redis 队列。

> 使用前请先创建 `{_RUNTIME}/async` 目录，框架不会自动创建。

## 保存任务

```php
$this->async('taskKey', ['id' => 1]);          //立即执行
$this->async('taskKey', ['id' => 1], 60);      //60 秒后执行
$this->async('taskKey', ['id' => 1], time() + 3600); //指定执行时刻（大于 1e9 时视为时间戳）
```

第 3 个参数小于 1000000000 时按"多少秒之后"处理，否则按绝对时间戳处理。
文件名为 `{microtime}.{uniqid}.log`，内容为 `serialize(['key' => ..., 'args' => ..., 'time' => ...])`。

## 读取并执行

```php
$this->asyncIterator(function ($key, $args, $file) {
    //按 $key 分派到具体处理逻辑
    switch ($key) {
        case 'sendMail':
            //...
            break;
    }

    return true;   //返回 true 表示事务执行完，文件会被删除
}, false);
```

- 回调的三个参数：任务键、参数数组、任务文件全路径；
- 只有到执行时间的任务才会被回调；
- 回调返回 `=== true` 时删除任务文件；第 2 个参数传 `true` 时无条件删除；
- **建议在回调里自行返回 `true`**，未返回则表示事务未执行完，下次继续；
- 无法反序列化的空文件会被跳过（第 2 参数为 `true` 时直接删除）。

## 独立遍历

`esp\help\AsyncIterator` 实现了 `Iterator`，可直接遍历目录中的文件内容：

```php
use esp\help\AsyncIterator;

$iterator = new AsyncIterator();              //默认目录 {_RUNTIME}/async
foreach ($iterator as $content) {
    $data = unserialize($content);
}
```

## 常驻进程建议

一般写一个 CLI 常驻脚本循环调用 `asyncIterator()`，例如每 5 秒一轮；
配合 swoole 的 `tick`，或直接用 `supervisor`/`systemd` 守护。
