# 关于视图`View`和`layout`

## 基本概念

- 一个控制器动作对应一个**子视图**，子视图被包含在**框架视图（layout）** 中；
- 视图文件里可以直接写原生 PHP，也可以用 `{@var}` 之类的标签，后者需要注册标签解析器，见 [标签解析器](./9.adapter.md)；
- 视图由 `Response` 在最后渲染，只有当控制器返回 `null` 且非 ajax 请求时才会渲染（见 [结果显示](./7.response.md)）。

若 `view_use` 被关闭（ `$this->setView(false)` ），则不产生视图内容；此时若也没有用 `json`/`text` 等方式输出，网页什么都不会显示。

## 视图目录与文件名

默认视图目录：`{directory}/{_VIRTUAL}[/{_MODULE}]/views`
例如 `/application/www/views`、`/application/www/jobs/views`。

默认视图文件名：`{控制器名}/{动作名}.php`，例如 `IndexController::indexAction()` 对应 `views/index/index.php`。

相关配置在 `response.ini` 中：

```ini
;固定指定视图目录（不指定时按上面的规则推算）
views = {_ROOT}/template/default

;视图文件扩展名，默认 php
extend = php
```

控制器中也可以临时改变：

```php
$this->setViewPath('/template/default'); //@开头=系统绝对目录；/开头=相对 _ROOT；其它=相对 application/{virtual}[/module]
$this->setView('index/list');            //不含扩展名时自动补，不含 / 时自动补当前控制器名
$this->setView(false);                   //关闭视图
```

查找视图文件时，若 `.php` 不存在会再试一次 `.phtml`；两者都不存在则报错终止。

## 框架视图 layout

每个控制器可以有一个默认框架 `layout.php`，该控制器下所有视图都使用此框架。
查找顺序（`View::builderViewFile()`）：

1. `{视图目录}/layout.php`
2. `{当前子视图文件所在目录}/layout.php`
3. `{视图目录的上一级}/layout.php`

三步都找不到则报错，所以必须至少存在一个 layout，或在动作中关闭框架 `$this->setLayout(false)`。

控制器中也可以直接指定框架文件：

```php
$this->setLayout('layout');     //非 / 开头：指当前视图目录下的文件
$this->setLayout('/pub/layout');//以 / 开头，依次尝试：
                                //   该路径本身（须在 _ROOT 内）
                                //   {_ROOT}/pub/layout.php
                                //   {_ROOT}/application/{_VIRTUAL}/views/pub/layout.php
$this->setLayout(false);        //关闭框架
```

路由表中也可以用 `view[layout]` 指定，见 [路由](./5.routes.md)。

### layout 中的内容

子视图渲染后的 HTML 以变量 `$_view_html` 送入 layout，layout 中输出它即可：

```php
<!DOCTYPE html>
<html>
<head>
    <title><?= $_title ?></title>
    <?= $_meta ?>
    <?= $_css ?>
    <?= $_js_head ?>
</head>
<body>
<?= $_view_html ?>
<?= $_js_foot ?>
</body>
</html>
```

### layout 的固定变量

以下 7 个变量由系统统一生成，正常情况下送入 layout 中可读；若关闭了 layout，则会被释放到子视图中：

| 变量          | 说明                                                              |
|-------------|-----------------------------------------------------------------|
| `_title`    | 网页标题，由 `response.ini` 的 `title` 与 `$this->title()` 组合而来         |
| `_meta`     | 已拼好的 `<meta />` 串，含 keywords、description 及 `$this->meta()` 增加的项 |
| `_css`      | 已拼好的 `<link />` 串，由 `$this->css()` 增加                           |
| `_js_head`  | 放在 `<head>` 中的 js                                               |
| `_js_body`  | 放在 `<body>` 中的 js                                               |
| `_js_foot`  | 放在页尾的 js，`$this->js()` 的默认位置                                    |
| `_js_defer` | 带 `defer` 属性的 js                                                |

`$this->css()`、`$this->js()` 传入的路径：以 `http`、`//` 或 `/` 开头时原样使用，否则自动补上资源域名；
值为 `jquery` 时替换为 `response.ini` 中配置的 jquery 地址。

## 关闭/开启自动渲染

```php
$this->render(false);   //Response::autoRun(false)，不自动输出任何内容
$this->concat(true);    //合并页面中的 js/css
```

## Markdown 视图

```php
$this->md('/md/readme.md');             //以 markdown 方式渲染指定文件
$this->md(['file' => 'a.md', 'css' => '/css/md.css', 'md' => []]);
$this->markdown('# 标题');               //直接得到转换后的 html 串
```

`md` 方式下视图文件扩展名用 `.md`，先渲染成 html，再交给 layout。

## ajax 请求

```php
$this->ajax('index/list');  //ajax 请求时自动关闭 layout 并改用指定视图
```

注意：`Response::display()` 中，若控制器返回 `null` 且当前是 ajax 请求，则直接结束，不渲染任何视图。
所以纯 ajax 接口应当**返回数组（json）**，而不是返回 `null` 指望渲染视图。
